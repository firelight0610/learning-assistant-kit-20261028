# STM32 专注计时器

已知主控：STM32F103C8T6。下载器已根据实物和 USB 信息确认为标注 ST-LINK V2 的设备，安装官方驱动后 Windows 状态正常。用户指出的资料目录为 `D:/楚元喆/学习/STM32`，检查时为空；屏幕型号、接线及配套工程尚未确认。

**本目录目前提供完整计时核心和接入参考，不是可以直接烧录的固件。** 不根据芯片型号猜屏幕驱动、GPIO 或有效电平。

## 已实现的逻辑

- 默认 25 分钟；演示模式可设为 10 秒。
- 短按一次开始，再短按暂停，再短按继续。
- 长按 800 毫秒复位；松开长按后保持 READY，不误启动。
- 30 毫秒按键防抖；计时使用毫秒差，不使用阻塞延时倒数。
- 到时进入 DONE，保持零秒；长按复位后可以再次开始。
- 处理 32 位毫秒计数回绕；显示剩余秒数向上取整。

状态转换：`READY → FOCUS ↔ PAUSE → DONE`；任意状态长按回到 `READY`。

## 接入步骤

1. 用例程原有工具链完成一次编译、下载和点灯；先证明下载链路正常。
2. 按厂家图接屏幕，跑通原有显示例程；再验证按键按下时读到的状态。
3. 将 `include/focus_timer.h`、`src/focus_timer.c` 加入这个已能工作的工程。
4. 配置头文件搜索路径，移植 `port/stm32_hal_integration.example.c` 中的调用逻辑。
5. 用实际驱动映射以下四个板级函数，不能直接烧录未实现的参考文件。

| 函数 | 实际需要做的事 |
|---|---|
| `board_button_pressed()` | 读取已核实的 GPIO，把实际按下转换为 true |
| `board_led_write(on)` | 按真实引脚和有效电平控制 LED |
| `board_display_lines(line1, line2)` | 调用已跑通的屏幕驱动，显示状态与时间 |
| `board_uart_write_line(line)` | 通过已配置的串口输出一行文字，便于保留证据 |

HAL 工程完成屏幕、GPIO 初始化后，调用 `study_focus_init(true)` 进入 10 秒演示模式；在主循环每 5～10 毫秒调用 `study_focus_loop()`。25 分钟模式用 `study_focus_init(false)`。

若例程使用标准外设库，不必重建成 HAL 工程：提供同样的单调毫秒计数和四个板级操作，在原有主循环中调用计时核心即可。
