# 展示证据

- `web-desktop.png`、`web-mobile.png`：公网网页真实截图，来自未登录的浏览器实际操作验证。
- 邮件截图：本人实际收到邮件后补充，遮住邮箱地址；不要截图授权码。
- 硬件照片：实物接线、运行、暂停、到时状态，验证后补充。
- `web-before-redeploy.png`、`web-after-redeploy.png`：同一条测试任务在两次真实正式部署之间保留，已验证；之后已删除该测试任务。
- `verification.json`：电脑测试、公网验证及工作流链接的记录，明确未验证项。

文件夹中没有的证据不视为已完成。定时邮件和开发板实物效果不能用模拟图片替代。
