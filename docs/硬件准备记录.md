驱动安装记录：连接后 Windows 最初报告错误代码 28（缺少驱动）。从 [ST 官方 STSW-LINK009 页面](https://www.st.com/en/development-tools/stsw-link009.html)取得驱动，验证 x64 驱动目录签名有效；只安装匹配本设备的 `stlink_dbg_winusb.inf`。安装返回 0，复查设备状态正常。此结果仅证明电脑能识别下载器，开发板接线及下载功能仍待验证。

后续实测：供电亮灯后，使用校验过发布 SHA-256 的 xPack OpenOCD 0.12.0-7，以 100 kHz SWD 成功读取芯片寄存器，电压约 3.26 V。未执行烧录、擦除或复位命令；检查日志见 `evidence/stlink-read-chip.log`。这证明电脑、下载器与主控的通信已通，首次烧录仍未完成。

本次线色对应：灰白线 GND→GND，红线 SWCLK→SWCLK，橙线 SWDIO→SWIO，黄线 3.3V→3V3。颜色仅用于追踪同一根线，应按两端引脚名称连接。下一步先准备程序控制的 LED 闪烁，再接屏幕。教程原始闪灯例程使用 PA0 外接 LED，不能直接当作板载 LED 例程。
