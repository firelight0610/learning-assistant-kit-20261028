## 第一段：Git，约 20 分钟

先理解一句话：`commit` 把一组修改保存为本机版本，`push` 把版本上传到 GitHub。

先只做第一步，在 PowerShell 输入：

```powershell
cd "D:\Codex\workspaces\2026-10-20\124-10-28-github\outputs\learning-assistant-kit"

```

把实际输出发来，我们先看懂分支、同步状态和工作区。检查后再继续：

1. 亲手新建 `docs/my-learning.md`，写日期、今天亲手完成的一件事，以及你对 `commit` 和 `push` 的理解。
2. 用 `git status` 找到新文件；用 `git add docs/my-learning.md` 放入暂存区。
3. 用 `git diff --staged` 阅读将保存的内容。
4. 用 `git commit -m "docs: record my first learning step"` 保存。
5. 用 `git push` 上传，在 GitHub 确认文件和提交存在。

只提交自己的练习文件，不要直接使用 `git add .` 把不认识的文件一起提交。练习是否完成，以你的实际操作输出为准。
