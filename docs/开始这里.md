# 先完成一个小步骤

你不需要先学完网页、Python、STM32 和 Git。每天完成一个能验证的小目标。

## 今天先做什么

网页和手动邮件已经完成。现在从[下一轮行动：Git 与硬件起点](下一轮行动.md)开始，不必重复部署网页和配置邮箱。

1. 在项目文件夹空白处右键，选择“在终端中打开”，输入 `git status`。
2. 把实际输出发给我。我会先解释当前状态，再让你做下一步。
3. 确认开发板、下载器和屏幕，整理商家例程并填写[硬件准备记录](硬件准备记录.md)。

项目初始代码由助手准备，不等于你已学会 Git。第一次练习从检查仓库、阅读一次差异开始；不要为了练习随意删除代码。

## 每天的节奏

- 先用约 10 分钟确认昨天的版本仍能运行。
- 用 1～2 小时做当天项目，只加一个明确功能。
- 留约 20 分钟练 Git，15 分钟验收与记录。
- 遇到问题记录“做了什么、预期是什么、实际是什么”，保留原始报错。
